# Timer

A simple, mobile-friendly countdown timer hosted as a static web page via GitHub Pages.

## Features

- Preset durations: 5, 10, 15, and 25 minutes
- Adjustable time in 1-minute increments using +/− buttons
- Animated ring that drains as time counts down — turns amber in the last quarter, red in the final minute
- Audible beep on completion
- Pause, resume, and reset controls
- Dark mode support (follows system preference)
- Works as a home screen shortcut on Android and iOS

## Usage

Open the timer in your phone's browser and tap **Add to Home screen** to use it like an app.

Live URL: `https://mjcstudio.github.io/timer/timer.html`
